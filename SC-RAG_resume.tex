\section{项目经历}
\textbf{SC-RAG：面向随机计算文献的可追溯研究 Agent}
\hfill \textit{Python / FastAPI / Streamlit / Docker}\\
\textit{项目概述：}面向随机计算（Stochastic Computing）文献检索、证据问答与跨论文综述的研究 Agent。

\begin{itemize}
\item 针对 SC 论文术语精确匹配与跨语义召回的差异，构建 50 篇论文的 page-aware chunks，采用 BM25 + dense 的 RRF（$k=60$）融合并可选 Cross-Encoder 精排；Top-5 召回率为 \X。 \source{reports/reranker\_ablation.json 的 top5\_recall\_any}
\item 针对跨论文问题容易漏检目标文献的问题，采用规则驱动的有界 Agent loop：alias 缺失时定向补检、comparison 候选不足时改写查询；不使用自主 planner 以保持 grounding 可预测，并记录 \X 个可观测步骤。 \source{phase4 answer trace 的 agent\_trace.steps}
\item 针对模型改写引用、补全事实和生成未知来源的风险，建立 span-ID grounding contract、Pydantic 严格 schema、四态证据判定与一次 repair；58 题引用契约有效率为 \X。 \source{phase2/phase4 JSON 的 citation\_contract\_valid}
\item 将 query、混合检索、补检、ContextBudget（10 chunks/14,000 chars）、480-char span 切分、结构化生成、引用校验串成 FastAPI 服务，提供 5 个 REST endpoint，端到端 p50/p95 延迟为 \X/\X ms。 \source{reports/reranker\_ablation.json 的 end\_to\_end\_p50/p95\_latency\_ms}
\item 针对超时、畸形 JSON、未知 span、空证据和不完整比较，采用有限重试、单次 repair 与 fail-closed abstain；在 8 道 unanswerable 对抗题上的拒答正确率为 \X。 \source{reports/reranker\_ablation.json 的 abstain\_correctness}
\end{itemize}
